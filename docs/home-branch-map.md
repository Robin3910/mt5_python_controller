# 首页 功能分支脑图

> 路由 /home，菜单码 home，权限 MENU_HOME；顶栏「首页」入口管理员与普通用户都可见（按 home 菜单权限渲染）

本文件由 `scripts/export_branch_maps.mjs` 从 Canvas 源文件自动导出，Canvas 版本：`.cursor/projects/d-work-space-mt5-python-controller/canvases/home-page-branch-map.canvas.tsx`。

共 66 条可测分支，分 10 个一级模块。

## 目录

1. **① 节点可见范围（homeVisibleNodes）** — 4 条分支
2. **② 趋势观测模块（HubTrendEmbed compact）** — 13 条分支
3. **③ 汇总统计卡（5 张）** — 5 条分支
4. **④ 工具栏（搜索 / 筛选 / 排序）** — 8 条分支
5. **⑤ 节点卡片** — 8 条分支
6. **⑥ 卡片操作菜单（⋯）** — 5 条分支
7. **⑦ 主节点切换流程** — 8 条分支
8. **⑧ 空态与分页** — 6 条分支
9. **⑨ 实时数据来源** — 4 条分支
10. **⑩ 权限与访问控制** — 5 条分支

| `9.4` | ⑨ 实时数据来源 › 顶栏在线计数 | 顶栏「在线 N/M」用 store 的 onlineCount（全量节点口径，非首页可见口径），与首页统计卡口径不同 | hub.onlineCount 过滤的是 hub.nodes 全集 | 确认两个位置的在线数在有他人节点时会不同 |
| `10.1` | ⑩ 权限与访问控制 › 菜单权限 home | 无 home 菜单权限 → 路由守卫重定向到第一个有权限的菜单 | router.beforeEach：hasMenu(to.meta.menu) 为假 → firstAllowedPath | 去掉 home 权限后访问 /home，应被重定向而不是 403 |
| `10.2` | ⑩ 权限与访问控制 › 管理员也显示首页入口 | 顶栏「首页」入口条件是 hasMenu('home')——管理员拥有全部菜单，因此可见 | resolve_menus(is_admin=true) = ALL_MENU_CODES | 管理员登录后顶栏应看到「首页」入口，并可进入 /home |
| `10.3` | ⑩ 权限与访问控制 › 节点归属校验 | 平仓、设主节点等操作都要求节点属于本人 | owned_node_or_404：非本人节点按不存在处理（404） | 普通用户对他人节点操作应 404 |
| `10.4` | ⑩ 权限与访问控制 › 平仓菜单权限 | — | close_node 要求 MENU_NODES 或 MENU_DASHBOARD 任一 | 两个菜单都没有时平仓应被拒 |
| `10.5` | ⑩ 权限与访问控制 › active-tasks 权限 | — | require_menu(MENU_NODES)，普通用户若无 nodes 权限则预查 403（前端已忽略预查错误） | 无 nodes 权限时主节点切换仍能走通（预查失败被吞掉） |
