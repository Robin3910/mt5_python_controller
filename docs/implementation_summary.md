# 以损定量精确止损止盈调整 - 实施总结

## 实施完成日期
2026-11-26

## 目标
解决以损定量开仓中因最小步长和分散仓手数取整导致的止损/止盈偏差问题，确保最终风险金额精确等于预设的 `risk_amount`。

## 实现方案

### 核心改进

#### 1. 市价开仓流程（已实施）
- **流程**：下底仓 → 下所有分散仓（市价10笔一次打齐）→ 所有单成交后改一次SL/TP
- **改单时机**：所有11笔单（1底仓+10分散仓）都成交后
- **改单内容**：
  - 修改所有单的止损价（使用 `modify_sl_by_magic`）
  - 修改分散仓的止盈价（逐个修改，底仓保持TP=0）
- **精确计算**：基于实际成交的总手数和预设风险金额，重新计算止损距离和阶梯止盈

#### 2. 限价开仓流程（已实施）
- **流程**：挂单前精确计算参数 → 下底仓+分散仓（限价，全部带精确SL/TP）→ 无需改单
- **计算时机**：在下底仓前进行
- **精确参数**：利用固定的挂单价，提前精确计算所有单的止损和止盈价格
- **优势**：整个生命周期无需改单，减少网络调用和失败风险

### 技术实现

#### 新增函数（risk_sizing.py）

1. **`recalc_sl_tp_market(positions, cfg, spec, direction)`**
   - 市价开仓，所有持仓成交后重新计算精确参数
   - 输入：所有持仓列表、配置、品种规格、方向
   - 输出：新的止损距离、止损价、止盈跨度、阶梯止盈价列表
   - 包含完整的参数验证和错误处理

2. **`recalc_sl_tp_limit(entry_price, total_lot, cfg, spec, direction)`**
   - 限价开仓，挂单前精确计算参数
   - 输入：挂单价、总手数、配置、品种规格、方向
   - 输出：与市价相同的精确参数结构
   - 相同的精确计算公式保证一致性

#### 改造方法（strategy_runner.py）

1. **初始化新状态变量**
   - `_risk_sl_tp_modified`: 市价模式改单标记
   - `_risk_limit_precise_params`: 限价精确参数缓存

2. **改造 `_risk_open_base()`**
   - 限价模式：在下底仓前调用 `recalc_sl_tp_limit()` 获得精确参数
   - 更新计划的止损价为精确值

3. **改造 `_risk_send_order()`**
   - 限价模式：使用精确参数代替计划中的参数
   - 市价模式：保持原有逻辑（改单在后续处理）

4. **改造 `_risk_advance()`**
   - 市价模式：检查是否所有单都成交，触发改单
   - 调用新的 `_risk_modify_sl_tp_market()` 方法

5. **新增 `_risk_modify_sl_tp_market()`**
   - 市价模式的改单核心逻辑
   - 计算新参数 → 改所有单的SL → 改分散仓的TP
   - 完整的日志和错误处理
   - 改单失败后继续运行（降级处理）

### 核心公式

#### 止损距离
```
新的止损距离 = risk_amount × tick_size / (总手数 × tick_value)
```

#### 止损价
```
sign = 1 if BUY else -1
新的止损价 = entry_price - sign × 新的止损距离
```

#### 阶梯止盈
```
止盈跨度 = 新的止损距离 × rr_ratio
底仓TP = 0
分散仓i的TP = entry_price + sign × 止盈跨度 × i / count
```
